# Face-Controlled Wheelchair

## 📌 Project Overview
A smart wheelchair developed as our Polytechnic Diploma major project. The system allows the user to control wheelchair movement using facial gestures through a mobile-based control system.

## 🎯 Objectives
- Develop an alternative method of wheelchair control.
- Integrate mechanical and electronic systems.
- Develop a practical and user-friendly mobility solution.
- Gain hands-on experience in project development and system integration.

## ⚙️ Working Principle
Facial commands are detected through the control system and transmitted to the wheelchair controller. The controller processes the commands and operates the motors to move the wheelchair in the required direction.

## 🔧 Main Components
- Wheelchair frame
- DC/PMDC motors
- Arduino UNO
- Motor driver
- Bluetooth module
- Smartphone
- Battery
- Wheels and mechanical components
